# 🎮 운명의 크레인 (Fate in the Claw)
### 3D 아케이드 인형 뽑기 친구 추첨 게임

친구들과 함께 즐기는 고품질 3D 스타일의 인형 뽑기 공정 추첨 웹 애플리케이션입니다.
외부 이미지나 음원 파일에 의존하지 않고, 순수 **HTML, CSS, JavaScript**, **Three.js**, **Web Audio API**를 활용하여 언제 어디서나 즉시 실행 가능합니다.

---

## ✨ 핵심 기능 및 특징

### 1. 👥 참가자 입력 & 명단 관리
- 참가자 이름을 손쉽게 추가, 수정, 삭제 가능
- 최소 2명 이상 등록 시 게임 시작 활성화
- 추첨 전 참가자 명단 확인 화면에서 각 참가자의 당첨 확률(1/N)을 시각적으로 확인

### 2. ⚖️ 100% 공정한 추첨 알고리즘
- 참가자의 입력 순서나 화면 내 위치와 무관하게 모든 참가자가 동일한 확률 보장
- 크레인 집게 작동 전 JavaScript로 당첨자가 무작위로 결정
- 허탕 없이 사전에 결정된 당첨자의 인형을 크레인이 정밀 추적하여 정확히 들어올림

### 3. 🎨 9가지 다채로운 테마
1. **포켓몬** (피카츄, 파이리, 꼬부기, 이상해씨, 푸린, 이브이)
2. **산리오** (헬로키티, 마이멜로디, 쿠로미, 시나모롤, 폼폼푸린, 포차코)
3. **짱구는 못말려** (짱구, 흰둥이, 부리부리자에몬, 짱아, 액션가면)
4. **디즈니** (미키 마우스, 도널드 덕, 곰돌이 푸, 스티치, 올라프)
5. **지브리 캐릭터** (토토로, 꼬마 토토로, 가오나시, 먼지귀신, 지지)
6. **게임 캐릭터** (마리오, 소닉, 커비, 팩맨, 슬라임, 록맨)
7. **치이카와** (치이카와, 하치와레, 우사기, 쿠리만쥬, 모몽가)
8. **리락쿠마** (리락쿠마, 코리락쿠마, 키이로이토리, 차이로이코구마)
9. **전체 캐릭터 모음** (1~8번 모든 테마의 캐릭터를 자동으로 병합한 올스타 페스티벌)

### 4. 🧸 입체적인 3D 캐릭터 & 크레인 연출
- Three.js를 활용한 고품질 3D 캐릭터 피규어 (표정 데칼 및 각 참가자의 이름표 부착)
- 3지 집게(Claw)의 관절 개폐 모션 및 신축 와이어 케이블
- 인형이 집게에 낚여 올라올 때의 물리적인 흔들림(Wobble)과 텐션 연출

### 5. 👥 실제 오락실의 구경꾼/관객 3D 연출
- 인형 뽑기 기계 주변을 서성이고 구경하는 귀여운 3D 관객 캐릭터들 배치
- 대기 시 기계를 바라보며 서성이다가, 인형을 낚아 올리는 순간 두 팔을 번쩍 들고 환호하며 방방 뛰는 생생한 아케이드 분위기 연출

### 6. 🎵 Web Audio API 기반 테마별 오리지널 사운드
- 외부 음원 없이 브라우저 내장 신디사이저로 생성하는 9가지 테마별 맞춤 BGM
- 크레인 모터 작동음, 집게 찰칵 사운드, 인형 상승 텐션음, 당첨 팡파레 & 환호 효과음
- 상단 오디오 컨트롤러로 사운드 On/Off 및 볼륨 실시간 조절 가능

### 7. 🏆 당첨 결과 및 다시 뽑기
- 당첨자 이름 크고 화려한 네온 골드 타이포그래피 연출
- 다양한 랜덤 축하 문구 ('너 당첨!', '축하합니다!', '오늘의 주인공!', '행운의 신이 선택한 사람!' 등)
- 축하 컨페티(꽃가루 폭죽) 파티클 효과
- `다시 뽑기`(동일 멤버로 새로운 추첨) & `처음으로 돌아가기` 원클릭 지원

## 🚀 실행 방법

### 방법 1: 로컬 정적 서버로 실행 (권장)
현재 디렉터리에 내장된 경량 서버를 실행합니다:
```bash
node server.js
```
이후 웹 브라우저에서 `http://localhost:3000`으로 접속합니다.

### 방법 2: 브라우저에서 직접 열기
`index.html` 파일을 더블 클릭하여 크롬, 엣지, 사파리 등의 최신 브라우저에서 바로 열 수 있습니다.
